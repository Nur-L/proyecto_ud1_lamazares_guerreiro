Sigue la siguiente estructura:

\- css/estilos.css → Hoja de estilos

\- js/app.js → Interacción con el formulario

\- .gitignore → archivos que no queremos que se incorporen al repositorio de Git.

\- index.html → página web resultante

\- README.md → archivo de ayuda, en el que podemos poner información relevante para informar.
